# TouchGrass 🌱
A mobile-first interactive card gallery to document the places we've visited for easy recommendation to friends and family.

## Features 💻 
- **Search bar** to quickly filter places
- **Mobile-first responsive cards** using custom CSS grid
- **Copy Info button** to quickly copy place details to clipboard
- **CSV-driven** content for easy updates
- **Fully modular layout** with reusable card template

## Built With 👩‍💻
- PHP
- CSV data
- jQuery
- Custom CSS
